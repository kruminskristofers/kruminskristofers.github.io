# QGIS Resources

A short list of QGIS resources and data sources I find useful.

## Learning & Documentation

- [QGIS.org](https://qgis.org) — The official QGIS website: downloads, news, and community info.
- [QGIS Documentation](https://docs.qgis.org) — Official user manual, training manual, and PyQGIS developer cookbook.
- [QGIS Training Manual](https://docs.qgis.org/latest/en/docs/training_manual/) — A free, structured course that takes you from the basics to advanced analysis.
- [QGIS Tutorials and Tips](https://www.qgistutorials.com) — Step-by-step tutorials with sample data.
- [Free and Open Source GIS Ramblings](https://anitagraser.com) — Anita Graser's blog on QGIS, movement data, and spatial analysis.

## Community & Plugins

- [QGIS Plugin Repository](https://plugins.qgis.org) — Browse and download community plugins.
- [GIS Stack Exchange](https://gis.stackexchange.com) — Q&A forum for troubleshooting QGIS and wider GIS problems.

## Data Sources

- [Natural Earth](https://www.naturalearthdata.com) — Free public-domain vector and raster map data for cartography.
- [Geofabrik Downloads](https://download.geofabrik.de) — Regularly updated OpenStreetMap extracts by country and region.
- [Copernicus Data Space Ecosystem](https://dataspace.copernicus.eu) — Free Sentinel satellite imagery and Earth observation data.
